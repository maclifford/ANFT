Payment links & amounts

Internal tool. Update routine: edit below → Download payment-links.json → upload it to the repo’s data/ folder → deploy.

These amounts and Stripe links are set once per event type. Every event of that type inherits them automatically, so you never enter a link per event. Leave a link blank and the payment button simply stays hidden until you fill it in — safe to save at any time. (A single event can override any of these on its own record for special cases.)
